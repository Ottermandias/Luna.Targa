# Luna.Targa

A small .NET 10 library for reading and writing Targa (`.tga`) images.

- Read true-color, grayscale, and color-mapped images.
- Decode images to RGBA32 pixel data.
- Write true-color or color-mapped images with optional run-length encoding.

See `TargaReader` and `TargaWriter` for the API.

Included in [Luna](https://github.com/Ottermandias/Luna).
